# LUMEN

LUMEN stands for Lane-Use Monitoring for Event Notification: An Integrated Sensor and Computer Vision-Based System for Rural Blind Curves Lane Safety Enhancement and Accident Detection. It’s our capstone project for the final year.

Its subnodes are equipped with a 24 GHz millimeter-wave radar for vehicle detection, using ESP32 microcontrollers. Its main node is powered by a Raspberry Pi 5 with a wide-angle day/night camera, running a custom YOLOv8n computer vision model. All nodes are interconnected through 433 MHz transceiver modules, and the entire system is solar powered.
